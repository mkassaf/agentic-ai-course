Before your first call

A notebook and a little Python.

Use a CPU runtime. Run one setup cell, then the short example. First-time package installation takes extra time.

{ }
01 / Bring the basics

Know your Python building blocks

Functions, lists, dictionaries, JSON, loops, and simple assertions. Know how to run a notebook cell and read an exception.

02 / Open a notebook

Run it in Google Colab

Open a lab with its Colab button. Save a working copy in your Drive, then run the cells from top to bottom. You can also download a notebook and use File → Upload notebook. Choose a CPU runtime.

03 / Choose a run mode

Practice, then call a real model

Start with MODE="practice". To try a live model, add FREEINFERENCE_API_KEY to Colab Secrets and set MODE="live". The helper uses FreeInference qwen3.6-35b by default. Other providers can be selected through make_ask(...).

04 / Observe the result

Make every call count

Read the answer, run the one check, then change one input. Keep credentials private. A passing check confirms one condition; read the result yourself too.

One interface, configurable providers: the live adapter expects an OpenAI-compatible Chat Completions API. FreeInference is the initial configuration; a university gateway or another compatible service can use the same adapter. Check current model access, quota, and API compatibility before class. The same model can serve every introductory example. One setup cell installs reusable course helpers from a pinned public GitHub revision, plus the relevant SDK where needed. Supporting code lives in the package, outside the notebooks.
